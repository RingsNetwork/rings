# Rings logo assets

`rings.svg` and `rings-white.svg` are the light- and dark-background variants of
the Rings gear mark.

The surrounding gear is adapted from the
[Rust logo artwork](https://github.com/rust-lang/rust-artwork/tree/main/logo),
which is distributed under the Creative Commons Attribution license. The Rings
variant replaces the center letterform with the Rings `R` and provides black and
white color variants. This project is not endorsed by or affiliated with the Rust
Foundation.
