{\centering\bfseries Abstract\par}%

\noindent
The Rings onion data plane interprets two layers, \emph{relay} and
\emph{exit}, and answers along the reversed path through relays that keep
per-circuit return state and forward one client-bound ciphertext
byte-identical.  We generalise the circuit to a term over a static
signature $\Sigma$ of shape symbols, backend names being open
registration data: nodes are partial $\Sigma$-algebras that register
shapes and (shape, backend) pairs, never applications; a circuit is a
client-sealed loop $\cl\to g\to\cdots\to g\to\cl$ that evaluates one
application per hop and composes them in the Kleisli category of the hop
effect monad, with $\relay$ as the identity: an onion Kleisli pipeline,
not a monad.  Each segment holds $s=2$
relays, the guard counting in both end segments; every hop parses one
uniform layer of a fixed-length Sphinx-style header; values travel in a carry slot of one width per loop, enciphered with AEZ, one
length-preserving layer per relay and one authenticated layer per
consumer; replies to world-facing sessions ride single-use reply blocks,
batched into credit loops, reaching $\ge1$\,MB/s per client at the
16\,KiB class.  We state eleven laws, among them
noninterference over hop views, position hiding, client path authority
(which admits Arrow composition and excludes monadic bind), byte
unlinkability, and
single-use admission, list the residual leakage, and map each law to a
test obligation.\par\vspace{0.6\baselineskip}}}

\section{Introduction}

Today's circuit is the term $\relay^{k}\then(\mathit{svc},\mathit{body})$
evaluated on the forward path and answered on its reverse
(\S\ref{sec:current}).  This paper states the general structure, the
onion Kleisli pipeline, of which today's circuit is the degenerate
instance, as definitions D1--D9 and laws L1--L10 and L5$'$ of issue \#834,
numbered identically.  Design lineage: Sphinx headers and
wide-block payloads~\cite{Danezis2009}, reply blocks~\cite{Chaum1981,
Danezis2003}, loops~\cite{Piotrowska2017}, AEZ~\cite{Hoang2015}, Kleisli
semantics~\cite{Moggi1991}, generic effects~\cite{Plotkin2003,
Plotkin2009}, and the Arrow/Selective hierarchy~\cite{Hughes2000,
Lindley2011,Mokhov2019}.

\section{Signature and Algebras}\label{sec:sig}

\begin{defD}{D1$'$}{signature of shapes}
$\Sigma$ is a finite, statically defined table of \emph{shape} symbols,
\begin{gather*}
\Sigma=\{\relay,\mathsf{tcp},\mathsf{https}\}\cup\Sigma_{\mathsf{invoke}},\\
\Sigma_{\mathsf{invoke}}=\{\mathsf{invoke}\langle\In,\Out,W,L\rangle :
W\in\mathcal W,\ L\in\mathcal L\},
\end{gather*}
$\In,\Out$ carried types and $\mathcal W,\mathcal L$ protocol-fixed
discrete classes of widths and latencies, so the table is finite.  Each $f\in\Sigma$ has
\[
\spec(f)=(\Args_f,\In_f,\Out_f,W(f),L(f),\pos(f)),
\]
$\Args_f$ client constants, $\In_f,\Out_f$ carried types, $W(f)\in\mathbb{N}$
the exact output width in bytes of a fixed-width shape, $L(f)$ the exact
latency class, $\pos(f)\subseteq\{\Int,\WF\}$.  Backend names are
\emph{not} symbols: they range over the open set
\[
\Omega=\{\omega\in[\mathtt{a\text{-}z0\text{-}9.\_\text{-}}]^{*} :
|\omega|\le32\}
\]
of registration data (D2) and arguments (D3); e.g.\ a \code{jev.typesafe}
backend is an application of $\mathsf{invoke}\langle\mathit{State},
\mathit{Answer},64,L_{500}\rangle$.  $W,L$ are fixed by the shape, not by
the operator, so L3, L4, L5 and L5$'$ are unchanged.  The identity is
\[
\relay:X\to X,\qquad L(\relay)=0 ;
\]
$\relay$ has no $W$: it preserves the slot width $C$ (L3).  A stream
symbol has no $W$ either: its frames are bounded by the slot of their
loop (L3), which the client chooses.  Closure:
\begin{gather*}
\{f\in\Sigma:\WF\in\pos(f)\}=\{\mathsf{tcp},\mathsf{https}\},\\
\omega\in\Omega\ \text{only in}\ (f,\omega),\ f\in\Sigma_{\mathsf{invoke}},\\
f\in\Sigma_{\mathsf{invoke}}\Rightarrow\pos(f)=\{\Int\}\ \text{(one-shot)}
\end{gather*}
(\code{wss}, \#847, joins the world-facing shapes after the cutover): an
open name is never a world-facing or session symbol, so it cannot bypass
D2$'$.  An unknown shape is rejected at configuration, at descriptor
decode, and at route construction; no name falls back to another shape.
An operator exposing TCP targets registers \code{tcp} and restricts
targets by policy.
\end{defD}

\begin{defD}{D2}{registration}
Node $n$ registers
\[
\mathrm{Reg}_n\subseteq\{\relay,\mathsf{tcp},\mathsf{https}\}\cup
(\Sigma_{\mathsf{invoke}}\times\Omega),
\]
a shape for $\relay,\mathsf{tcp},\mathsf{https}$ and a pair
$(f,\omega)$ for $\mathsf{invoke}$; $\Sigma_n\subseteq\Sigma$ is the set of
shapes in $\mathrm{Reg}_n$.  $n$ is a partial $\Sigma$-algebra: for each
$f\in\Sigma_n$ a generic effect~\cite{Plotkin2003}
\[
\sem{f}_n:\Args_f\times\In_f\to M\,\Out_f ,
\]
defined for $\mathsf{invoke}$ on $\bar a=(\omega,\bar a')$ iff
$(f,\omega)\in\mathrm{Reg}_n$; $M$ is the hop effect monad (failure, delay,
world I/O).  $n$ publishes $\mathrm{Reg}_n$, never an application.  Every
registration, $\relay$ included, carries $n$'s process epoch $e_n$, drawn
afresh at each process start: $\relay$ in
\code{OnlineNodeDescriptor::capabilities} extended with $e_n$, every other
entry in one signed descriptor per (shape, backend) with $e_n$ and
$\quota(n,f,\omega)$ ($\omega=\epsilon$ for a named shape); $\omega$ is canonical and validated against the
signed descriptors, not against a code table.
Registration includes $\relay$: $\mathrm{Reg}_n\ne\emptyset\Rightarrow\relay\in
\mathrm{Reg}_n$, so a neighbour's registry entry does not reveal whether a relay
is adjacent to a symbol hop.
\end{defD}

A node is a handler~\cite{Plotkin2009} for the operations it registers;
$\Int$ symbols are one-shot.

\begin{defD}{D2$'$}{session symbol}
A $\WF$ session symbol (\code{tcp}, \code{https}) is a stream symbol:
$\Args_f\ni(\sid,\mathit{target})$ with a session id
$\sid\in\{0,1\}^{128}$ drawn by $\cl$ per session, and
$\In_f=\Out_f=\mathrm{Frame}$,
\begin{gather*}
\enc(\mathrm{data}(w))=\mathtt{00}\,\|\,w,\qquad
\enc(\mathrm{fin})=\mathtt{01},\\
\enc(\mathrm{credit}(\upsilon_1..\upsilon_k))=\mathtt{02}\,\|\,\upsilon_1\|\cdots\|\upsilon_k,
\end{gather*}
with $|w|\le C_0-2$ (L3) and $\upsilon_j$ SURBs of $\sid$ (D8).  $h$ opens $\sid$ at its first forward loop,
binding it to $\mathit{target}$, and rejects a later loop of $\sid$ with
another target.  $\mathrm{data}(\epsilon)$ is a credit-only loop.
$\mathrm{fin}$ closes one direction; $h$ drops $\sid$ once both directions
are closed, or once no forward loop of $\sid$ has arrived for $V$.
For \code{https} the frames carry the HTTPS request/response encoding;
TLS tunnels use \code{tcp}.
\end{defD}

\begin{defD}{D3}{application}
An application is $(f,\bar a)$, $\bar a\in\Args_f$, typed
$(f,\bar a):\In_f\rightsquigarrow\Out_f$; it is sealed in the layer of the
hop that evaluates it and visible to no other hop.  For
$f=\mathsf{invoke}\langle\cdots\rangle$ the backend name is the first
component, $\bar a=(\omega,\bar a')$, and shares the padded $A=64$ bytes:
$|\enc(\omega,\bar a')|\le A$, larger inputs travel in the carry.  The
public symbol word $\sigma$ therefore shows shapes only, never $\omega$.
\end{defD}

\section{Pipelines}\label{sec:pipeline}

\begin{defD}{D4a}{pipeline}
Pipelines are the morphisms of the free category $\Free(G_\Sigma)$ on
the graph $G_\Sigma$ with types as vertices and applications as edges;
composition is
\[
\frac{\theta:X\rightsquigarrow Y\qquad \vartheta:Y\rightsquigarrow Z}
     {\theta\then\vartheta:X\rightsquigarrow Z}.
\]
$P=(f_1,\bar a_1)\then\cdots\then(f_n,\bar a_n)$ is well formed iff
\begin{gather*}
1\le n\le n_{\max}=4,\qquad\forall k<n:\ \Out_{f_k}=\In_{f_{k+1}},\\
\forall k<n:\ \Int\in\pos(f_k),\\
f_n\text{ is a }\WF\text{ session symbol}\ \Rightarrow\ n=1 .
\end{gather*}
Violations are rejected at construction.  The bound $n_{\max}$ is
\code{MAX\_ONION\_LOOP\_SYMBOLS}.
\end{defD}

\begin{defD}{D4b}{Kleisli denotation}
For $\phi:X\to MY$, $\psi:Y\to MZ$ in $\Kl(M)$~\cite{Moggi1991},
$\phi\then\psi=\mu_Z\circ M\psi\circ\phi$.  A placed application
$(f,\bar a,h)$ with $\sem{f}_h(\bar a,-)$ defined (D2) is an edge of the graph $G^N_\Sigma$
of placed applications, $N$ the nodes; the unique functor
$\sem{-}:\Free(G^N_\Sigma)\to\Kl(M)$ sending it to
$\sem{f}_h(\bar a,-)$ gives, for $P$ placed on $h_1..h_n$,
\[
\sem{P}(v_0)=\bigl(\sem{f_1}_{h_1}(\bar a_1,-)\then\cdots\then
\sem{f_n}_{h_n}(\bar a_n,-)\bigr)(v_0),
\]
and $\sem{P\then P'}=\sem{P}\then\sem{P'}$.  The client consumes
$\sem{P}(v_0)$.
\end{defD}

\begin{lawL}{L1}{identity}
$\sem{\relay}=\eta$, hence $\relay\then f=f=f\then\relay$ on values.  The
loop builder factors through $\nf$, which deletes $\relay$ applications:
$\LoopOf(P)=\LoopOf(\nf P)$, so $\LoopOf(\relay\then P)\eqd\LoopOf(P)$ and every
hop's view is unchanged.
\end{lawL}

\begin{lawL}{L2}{associativity}
$(f\then g)\then h=f\then(g\then h)$ on values; immediate from the monad
laws, and $\Free(G_\Sigma)$ has no bracketing.
\end{lawL}

$\nf$ and L1 on views apply from Phase~2a.  Phase~1 admits only
$\relay^{k}\then(f,\bar a)$ with $\WF\in\pos(f)$, which
is today's circuit (\S\ref{sec:current}).

\section{The Loop}\label{sec:loop}

\begin{defD}{D4c, D5}{loop, segment}
Let $\cl$ be the client and $g$ its entry guard.  Segment $k\in[0,n]$
is $s=2$ relays $r_{k,1}..r_{k,s}$ (\code{ONION\_SEGMENT\_RELAYS}) from producer $p_k$ to consumer $c_k$,
\begin{gather*}
p_0=\cl,\quad p_k=h_k,\quad c_k=h_{k+1},\quad c_n=\cl,\\
\LoopOf(P):\ \cl\to r_{0,1..s}\to h_1\to r_{1,1..s}\to\cdots\\
\to h_n\to r_{n,1..s}\to\cl .
\end{gather*}
Positions are $i\in[1,H]$; position $i$ evaluates $f_i$,
which is $\relay$ on every $r_{k,j}$.  $\LoopOf(\nf P)$ is the symbol word
$\relay^{s}f_1\relay^{s}\cdots f_n\relay^{s}$.
\end{defD}

\begin{lawL}{L7}{guard closure}
$r_{0,1}=r_{n,s}=g$: the guard is relay $1$ of segment $0$ and relay $s$
of segment $n$.  The other $H-2$ positions carry pairwise distinct DIDs,
distinct from $g$.  $g$ is the only hop adjacent to $\cl$.
\end{lawL}

\begin{proposition}[Loop size]\label{prop:size}
With $n$ symbol hops and $n+1$ segments of $s$ relays,
\begin{gather*}
H(n,s)=n+(n+1)s=(s+1)n+s,\\
\#\mathrm{DID}=H-1,\qquad E=H+1\ \text{cells},\\
\Hm=H(n_{\max},s)=(s+1)\cdot4+s=14 .
\end{gather*}
\end{proposition}
\begin{proof}
Segments contribute $(n+1)s$ positions; L7 repeats exactly one DID; the
$H$ positions lie on a path from $\cl$ to $\cl$ of $H+1$ edges.
\end{proof}

\begin{proposition}[Segment length]\label{prop:s}
$s=2$ is the least $s$ at which no single node is adjacent to both $\cl$
and a symbol hop.
\end{proposition}
\begin{proof}
$s=0$ violates L7.  At $s=1$, $r_{0,1}=r_{0,s}=r_{n,1}=r_{n,s}=g$, so $g$
alone is adjacent to $\cl$, $h_1$ and $h_n$, and for $n=1$ links $\cl$ to
its world-facing $h_1$.  At $s=2$, $g$ neighbours only $\cl$, $r_{0,2}$,
$r_{n,1}$.
\end{proof}

Relays do not mix ($L(\relay)=0$), so a timing-correlating coalition skips
middle relays: $s\ge3$ adds $n+1$ edges of latency per relay and no
anonymity.  At $(s,n)=(2,1)$, $E=6$ and the forward prefix
$g,r_{0,2},h_1$ is Tor's three-hop circuit~\cite{Dingledine2004}.

Route validation checks $H=(s+1)n+s$ with exactly $s$ relays between
consecutive symbol hops, and admits $g$ exactly twice, at positions $1$
and $H$ (\code{has\_duplicate\_dids}); selection fails closed when fewer
than $H-1$ distinct eligible DIDs exist.  \code{MAX\_ONION\_LOOP\_HOPS}
$=\Hm$ is derived from $s$ and $n_{\max}$ and replaces
\code{MAX\_ONION\_CIRCUIT\_HOPS}~$=8$; \code{DEFAULT\_ONION\_ROUTE\_HOPS}
and \code{OnionRouteRequest::\{hop\_count, allow\_short\_paths\}} are
removed, since a short path is a distinguishable segment length (D5).

\section{Uniform Layer and Timing}\label{sec:layer}

\begin{defD}{D6}{uniform layer}
Every position $i$ has one layer shape
\[
\lambda_i=(f_i,\bar a_i,\nxt_i,e_i,x,\nu_i,\kappa_i,\gamma_{i+1})
\]
of $\ell$ bytes, with $\bar a_i$ padded to $A$ bytes: epoch $e_i$, one
expiry per loop,
\begin{gather*}
x=\lceil t_{\mathrm{build}}/Q\rceil\,Q+X_0,\\
Q=30\,\mathrm{s},\qquad X_0=V-Q=120\,\mathrm{s},
\end{gather*}
a function of the build quantum only ($X_0$ is today's
\code{ONION\_FORWARD\_PAYLOAD\_TTL\_MS}), replay nonce
$\nu_i$, carry seeds $\kappa_i=(\sigma^{\mathrm{in}}_i,\sigma^{\mathrm{out}}_i)$
(D7), and the next hop's MAC $\gamma_{i+1}$ (Def.~\ref{def:header}); there
is no tag field (D6$'$).  A relay has $\bar a_i=()$ and random
$\sigma^{\mathrm{out}}$.  Each loop has one class $b\in\mathfrak B$, today's
cell buckets above 4\,KiB ($16$\,KiB to $12$\,MiB), chosen by $\cl$; the
cell on every edge of the loop, SURB replies included, is
\begin{gather*}
\alpha_{i+1}\,\|\,\beta_{i+1}\,\|\,\gamma_{i+1}\,\|\,y_i,\qquad
|\beta|=\Hm\ell,\\
|y_i|=C_b=b-|\chi|,\qquad |\mathrm{cell}|=b ,
\end{gather*}
with framing $F=0$: $b$ is decoded from the cell length, and no class byte
exists that could disagree with it.  Consequences of $F=0$:
\begin{itemize}
\item no per-edge cell AEAD: integrity is $\gamma$, and the previous hop
  is the authenticated transport link $\frm$;
\item link padding (cover) is a uniform class-$b$ cell; the receiving
  hop rejects it at $\alpha$ decoding with probability $\approx1-2^{-8}$
  (a random 33-byte string is a valid SEC1 point with probability
  $\approx2^{-8}$), and otherwise at $\gamma$, except with probability
  $2^{-128}$;
\item every received cell is charged $u(b)$ on receipt, before $\alpha$
  decoding and the ECDH (L9);
\item $\gamma$ is checked before any insertion into $R_i$ and before
  admission (Algorithm~\ref{alg:hop}).
\end{itemize}
\end{defD}

\begin{defD}{D6$''$}{header encoding}
Key transport is Sphinx's single blinded group element $\alpha$ (33\,B);
DIDs are raw 20\,B; carry keys travel as 32-byte seeds.  With
$A=64$,
\begin{gather*}
\ell=\underbrace{1}_{f}+\underbrace{64}_{\bar a}+\underbrace{20}_{\nxt}
+\underbrace{16}_{e}+\underbrace{8}_{x}\\
+\underbrace{16}_{\nu}+\underbrace{64}_{\kappa}+\underbrace{16}_{\gamma}
=205\,\mathrm{B},\\
|\beta|=\Hm\ell=14\cdot205=2870\,\mathrm{B},\\
|\chi|=33+2870+16=2919\,\mathrm{B},\\
C_{16\,\mathrm{KiB}}=16384-2919=13465\,\mathrm{B}\ (82\%).
\end{gather*}
\end{defD}

\begin{definition}[Fixed-length header]\label{def:header}
Hop $i$ derives $K_i$ from $\alpha_i$ and its secret key, blinds
$\alpha_{i+1}=\alpha_i^{\,\mathrm{Hash}(\alpha_i,K_i)}$, and expands
$\rho_i=\PRG(K_i)\in\{0,1\}^{(\Hm+1)\ell}$; $\rho[a,b)$ is a byte range in
units of $\ell$.  It checks the $16$-byte $\gamma_i=\MAC_{K_i}(b\,\|\,\beta_i)$, $b$ the class, and peels
\[
(\beta_i\,\|\,0^{\ell})\oplus\rho_i=\lambda_i\,\|\,\beta_{i+1}.
\]
The client builds, for $1\le i<H$, with $R$ uniform,
\begin{gather*}
\phi_0=\epsilon,\quad
\phi_i=(\phi_{i-1}\|0^{\ell})\oplus\rho_i[\Hm{-}i{+}1,\Hm{+}1),\\
\beta_H=\bigl((\lambda_H\|R)\oplus\rho_H[0,\Hm{-}H{+}1)\bigr)\,\|\,
\phi_{H-1},\\
\beta_i=\bigl(\lambda_i\,\|\,\beta_{i+1}[0,\Hm{-}1)\bigr)\oplus
\rho_i[0,\Hm),\\
\gamma_i=\MAC_{K_i}(b\,\|\,\beta_i).
\end{gather*}
\end{definition}

This is Sphinx's header~\cite{Danezis2009}: one blinded group element
per packet and per-hop PRG filler with MACs the client precomputes.

\begin{proposition}[Header correctness]\label{prop:header}
For $H\le\Hm$ and $1\le i<H$, peeling $\beta_i$ under $K_i$ yields
$(\lambda_i,\beta_{i+1})$, peeling $\beta_H$ yields $\lambda_H$, and every
$\gamma_i$ verifies on a cell of the loop's class $b$.
\end{proposition}
\begin{proof}
By induction down from $H$, the last $i-1$ blocks of $\beta_i$ are
$\phi_{i-1}$: true at $H$ by construction, and expanding $\beta_i$ and
$\phi_i$ carries it from $i+1$ to $i$.  So the first $\Hm$ blocks of
$(\beta_i\|0^\ell)\oplus\rho_i$ are $\lambda_i\|\beta_{i+1}[0,\Hm{-}1)$,
and its last block $\rho_i[\Hm,\Hm{+}1)$ is the last block of $\phi_i$,
hence of $\beta_{i+1}$.  The client computes $\gamma_i$ over $b\|\beta_i$,
the bytes hop $i$ receives in a class-$b$ cell.
\end{proof}

\begin{lemma}[Header view]\label{lem:header}
For $H\le\Hm$, hop $i$'s view of $(\chi_i,\chi_{i+1})$ is, up to
$\Hm\,\epsilon_{\PRG}+\epsilon_{\MAC}+\epsilon_{\alpha}$, a function of
$\lambda_i$ and fresh coins alone, independent of $H$, $i$, and every
other layer.
\end{lemma}
\begin{proof}
$|\chi|$ is constant.  Hop $i$ unmasks $\lambda_i$ and $\beta_{i+1}$,
reads $\gamma_{i+1}$ from $\lambda_i$, and computes $\alpha_{i+1}$ from
$\alpha_i$ and $K_i$.  By DDH, $\alpha_i$ is a uniform group element to $i$,
unlinkable to every other hop's $\alpha_j$ and independent of $H$ and $i$
($\epsilon_\alpha$).  Every block of
$\beta_{i+1}$ but the last is masked by some $\rho_j$, $j\ne i$: by
$\rho_{i+1}$ when $i+1<H$, and by $\rho_H$ or an upstream term of
$\phi_{H-1}$ when $i+1=H$.  The last block is $\rho_i[\Hm,\Hm{+}1)$,
which $i$ computes itself.  Hybrids replacing the $\rho_j$, $j\ne i$, one
key at a time by uniform strings make $\beta_{i+1}$ uniform apart from
that block; $\gamma_{i+1}$ is then a $\MAC$ under an unseen key.
\end{proof}

\begin{lawL}{L3}{width}
The carry slot has width $C=C_b$ on every edge of a loop of class $b$.
With $C_0=C-\tau$, for fixed-width symbols the client picks the least
$b$ with $|\enc(v_0)|<C_0$ and $W(f_k)<C_0$ for all $k$; for a stream
symbol, whose frames carry up to $C_0-2$ bytes, $b$ is the client's choice
between throughput and leakage (Table~\ref{tab:leak}).  For a fixed-width
symbol $W$ factors through the output type ($W(f)=w(\Out_f)$, so the
width a consumer unpads is fixed by its own $\In$); a stream symbol
(D2$'$) carries one frame per loop or reply, and larger bodies span
several loops.  Further,
\[
\pad(b)=b\,\|\,\mathtt{80}\,\|\,\mathtt{00}^{C_0-|b|-1},\qquad
|\enc_f(w)|=W(f);
\]
an output with $|\enc_f(w)|>W(f)$, or a frame with $|\enc(w)|\ge C_0$,
fails closed, never truncated.
\end{lawL}

\begin{lawL}{L4}{timing}
$\dep_i=\arr_i+L(f_i)$ exactly.  An evaluation unfinished at $\dep_i$ is
dropped, never released late.  The one exception is a reply of a $\WF$
session symbol (Algorithm~\ref{alg:reply}): it leaves when world bytes are
ready, at any time before the SURB's $x$.
\end{lawL}

\section{Carry}\label{sec:carry}

Write $\Enc{\tau}{k},\Dec{\tau}{k}$ for AEZ v5~\cite{AEZv5,Hoang2015}
encryption and decryption with empty nonce and associated data;
$|\Enc{\tau}{k}(m)|=|m|+\tau$, and $\Dec{\tau}{k}$ returns $\bot$ unless
the deciphered block ends in $\tau$ zero bytes.

\begin{defD}{D7}{carry}
For segment $k$ the client draws one 32-byte segment seed $\sigma_k$ and
derives, with HKDF-SHA256 under distinct domain tags,
\begin{gather*}
\sigma_{k,j}=\KDF_{32}(\sigma_k,j),\quad \sigma_{k,c}=\KDF_{32}(\sigma_k,c),\\
k_{r_{k,j}}=\KDF_{48}(\sigma_{k,j}),\qquad k_{c_k}=\KDF_{48}(\sigma_{k,c}),
\end{gather*}
re-drawing $\sigma_k$ if a derived key has a zero AEZ subkey
($\approx2^{-128}$).  It places $\sigma^{\mathrm{out}}_{p_k}=\sigma_k$,
$\sigma^{\mathrm{in}}_{r_{k,j}}=\sigma_{k,j}$, and
$\sigma^{\mathrm{in}}_{c_k}=\sigma_{k,c}$.
With $b_k=\pad(\enc(v_k))$ and $\tau=16$:
\begin{gather*}
y_{k,0}=\Enc{0}{k_{r_{k,1}}}\circ\cdots\circ\Enc{0}{k_{r_{k,s}}}
\circ\Enc{\tau}{k_{c_k}}(b_k),\\
y_{k,j}=\Dec{0}{k_{r_{k,j}}}(y_{k,j-1}),\qquad
b_k=\Dec{\tau}{k_{c_k}}(y_{k,s}).
\end{gather*}
A value of type $()$ is encoded as $\epsilon$, so every consumer
authenticates $\pad(\epsilon)$ and processing is uniform.
\end{defD}

\begin{lemma}[Relay carry]\label{lem:carry}
Under Assumption~\ref{as:prim} and L9, at $i=r_{k,j}$ the strings
$y_{k,j-1}$ and $y_{k,j}$ are uniform on $\{0,1\}^C$ and independent of
$v_k$.
\end{lemma}
\begin{proof}
$y_{k,j}=\Dec{0}{k_{r_{k,j}}}(y_{k,j-1})$ is $\Pi_k$ applied to one
input, for $k=k_{r_{k,j+1}}$ ($\tau=0$) or $k=k_{c_k}$ ($\tau=16$, input
$b_k\|0^{16}$): a fresh key not held by $i$ and used once by L9
(Prop.~\ref{prop:onekey}), hence a uniform string.  $y_{k,j-1}$ is its
image under a permutation keyed by $i$'s own key.
\end{proof}

Every layer carries exactly one inbound and one outbound seed, so
$|\kappa_i|=64$\,B reveals no position.  AEZ v5 is implemented in-repo on
RustCrypto \code{aes::hazmat} (constant-time, \code{wasm32}); its API takes
raw $48$-byte keys only (no Extract), a key with a zero subkey $I$, $J$ or
$L$ is rejected, and $\mathrm{GF}(2^{128})$ doubling is branch-free.  $C\ge32$ keeps every call on the AEZ-core
path, never AEZ-tiny.

\begin{proposition}[One value per key]\label{prop:onekey}
Under L9 every $k_{r_{k,j}}$ and $k_{c_k}$ is applied to exactly one
$C$-byte value: enciphered once by $p_k$, deciphered once by its holder.
\end{proposition}
\begin{proof}
Keys derive from a fresh $\sigma_k$ per segment (D7).  $p_k$ enciphers
its single output once under each key derived from
$\sigma^{\mathrm{out}}_{p_k}$.  The holder of $k$
deciphers only a cell whose layer names $k$, and L9 admits that layer
once, across restarts by the process epoch.  Without L9 a replayed cell
with a modified carry makes the holder a chosen-ciphertext oracle under a
fixed key: L9 is load-bearing for AEZ.
\end{proof}

\begin{algorithm}[t]
\caption{$\mathrm{Hop}_i(\frm,\chi,y,\arr)$: one position, all symbols}
\label{alg:hop}
\begin{algorithmic}[1]
\State $b\gets|\chi|+|y|$;\ $u\gets u(b)$
\State $\mathsf{tk}\gets\mathrm{charge}_i(\frm,u,\arr)$;\
  \textbf{if} $\mathsf{tk}=\bot$ \textbf{then} drop
  \Comment{L9}
\State $\alpha\gets\mathrm{sec1}^{-1}(\chi[0,33))$;\ \textbf{if}
  $\alpha=\bot$ \textbf{then} settle $\mathsf{tk}$;\ drop
\State $(\lambda,\chi')\gets\peel(\mathit{sk}_i,\alpha,\chi)$ \Comment{ECDH, $K_i$}
\If{$\gamma\ne\MAC_{K_i}(b\,\|\,\beta)$}\label{alg:hop:gamma}
  \State settle $\mathsf{tk}$;\ drop \Comment{D6, L8}
\EndIf
\If{$\neg\,\mathrm{admit}_i(\mathsf{tk},x,e,\nu)$}
  \State drop \Comment{consumes $\mathsf{tk}$; L9}
\EndIf
\State $R_i[x]\gets R_i[x]\cup\{\nu\}$;\
  $k^{\mathrm{in}}\gets\KDF_{48}(\sigma^{\mathrm{in}})$
\If{$f=\relay$} \State $y'\gets\Dec{0}{k^{\mathrm{in}}}(y)$
\Else
  \State $m\gets\Dec{\tau}{k^{\mathrm{in}}}(y)$;\ \textbf{if} $m=\bot$
    \textbf{then} drop \Comment{L8}
  \If{$f$ is a session symbol, $\bar a=(\sid,\mathit{target})$}
    \State $Q_{h,\sid}\gets Q_{h,\sid}\cup\{(\nxt,\chi',\sigma^{\mathrm{out}},x)\}$
      \Comment{D8}
    \State apply $\enc^{-1}\pad^{-1}(m)$ to session $\sid$: data, fin, or
      $\mathrm{credit}(\vec\upsilon)$ into $Q_{h,\sid}$ up to $Q_{\max}$
      (D2$'$, D8);\ \Return
  \EndIf
  \State $w\gets\sem{f}(\bar a,\enc^{-1}\pad^{-1}(m))$ by $\arr+L(f)$
    \Comment{L4}
  \If{late $\vee\ |\enc_f(w)|>W(f)$} \State drop \Comment{L3} \EndIf
  \State $y'\gets\Enc{0}{k_1}\circ\cdots\circ
    \Enc{0}{k_s}\circ\Enc{\tau}{k_{c}}(\pad\,\enc_f(w))$, keys from
    $\sigma^{\mathrm{out}}$
\EndIf
\State release $(\chi',y')$ to $\nxt$ at $\arr+L(f)$
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[t]
\caption{$\mathrm{Reply}_{h,\sid}(t_0)$: world bytes or EOF ready at
session $\sid$ of $h$}
\label{alg:reply}
\begin{algorithmic}[1]
\State $Q_{h,\sid}\gets\{\upsilon\in Q_{h,\sid}: t_0<x_\upsilon\}$
  \Comment{expired SURBs discarded}
\If{$Q_{h,\sid}=\emptyset$} \State pause reading;\ \Return
  \Comment{Inv.~\ref{inv:credit}}
\EndIf
\State $\upsilon=(\nxt,\chi,\sigma,x)\gets$ the element of least $x$
\State $Q_{h,\sid}\gets Q_{h,\sid}\setminus\{\upsilon\}$
  \Comment{single use}
\State $w\gets\mathrm{data}(\le C_0-2$ world bytes$)$, or $\mathrm{fin}$ at EOF
\State $y'\gets\Enc{0}{k_1}\circ\cdots\circ\Enc{0}{k_s}\circ
  \Enc{\tau}{k_c}(\pad\,\enc(w))$, keys from $\sigma$ (D7)
\State release $(\chi,y')$ to $\nxt$
\end{algorithmic}
\end{algorithm}

\begin{defD}{D6$'$}{client position}
$\cl$ is position $H+1$ and $\nxt_H$ is the DID of $\cl$, whose
connection $g$ already holds.  The tag is
\[
t_\cl:=\gamma_{H+1}\in\{0,1\}^{128},
\]
drawn by $\cl$ as the next-hop MAC field of $\lambda_H$; $g$ forwards it
as $\gamma$ of $\chi_{H+1}$ in a class-$b$ cell, as to any hop.  $\cl$ does
not verify $\gamma_{H+1}$ as a MAC: $k_{c_n}$ authenticates the carry.  A
tag field inside $\lambda_H$ would reach $g$ only, never $\cl$, so the
layer has none.
$\cl$ keeps $T:t_\cl\mapsto(k_{c_n},\text{loop})$, removes the entry on
first use or at $x$, and drops a cell with an unknown tag.  Every SURB ends
in its own tag: a forward loop's suffix in that loop's tag, a batched SURB
(D8) in a fresh one.
\end{defD}

$t_\cl$ is uniform and seen only by $g$ (in $\lambda_H$, then on the edge
$g\to\cl$) and by $\cl$, so it links nothing the guard cannot already link
by timing.

\section{Reply Blocks}\label{sec:surb}

\begin{defD}{D8}{SURB}
A single-use reply block for session $\sid$ at $h$ is the client-sealed
loop suffix after $h$:
\[
\upsilon=(\nxt,\chi_\upsilon,\sigma_\upsilon,x_\upsilon),\quad
|\upsilon|=20+2919+32+8=2979\,\mathrm{B}.
\]
$h$ keeps the suffix of every forward loop of $\sid$ that reaches it
($\chi_{i+1}$, $\sigma^{\mathrm{out}}_i$, $x$) as one SURB in
$Q_{h,\sid}$, adds the $k$ SURBs of a $\mathrm{credit}$ frame, and spends
a SURB only on a reply of $\sid$, removing it before release.  A pool holds
at most $Q_{\max}=256$ SURBs ($256\cdot2979\approx763$\,KB); credit beyond it is dropped,
and the pools of all sessions at $h$ count against $\quota(h,f,\epsilon)$.
\end{defD}

\begin{proposition}[SURB batching]\label{prop:batch}
A credit loop carries $k=\lfloor(C_0-2)/|\upsilon|\rfloor$ SURBs and
yields $k+1$ credits; upload is $1/(k+1)$ of download.  At $b=16$\,KiB,
\begin{gather*}
C_0-2=16384-2919-16-2=13447,\\
k=\lfloor13447/2979\rfloor=4 .
\end{gather*}
\end{proposition}
\begin{proof}
L5$'$ fixes $|\chi_\upsilon|=|\chi|$, so $|\upsilon|=2979$\,B (D8), and
$C_0=C_b-\tau$ with $F=0$ (D6).  The loop's own suffix is the
$(k{+}1)$-th SURB.
\end{proof}

With the 9.3\,KB header of the per-layer-envelope encoding a SURB did not
fit a 16\,KiB carry, and credit was one forward cell per reply cell;
D6$''$ removes that premise.

\begin{invariant}[Credit]\label{inv:credit}
For each session $\sid$ at $h$ let $Q_{h,\sid}$ be its unexpired SURBs
($t_\upsilon$ the arrival of $\upsilon$), $u(t)$ its SURBs received (one
per forward loop plus $k$ per credit frame) and $r(t)$ its replies emitted
by time $t$.  Then
\begin{gather*}
r(t)\le u(t),\qquad |Q_{h,\sid}|\le Q_{\max},\\
\upsilon\in Q_{h,\sid}\Rightarrow t<x_\upsilon\le t_\upsilon+V,\\
|Q_{h,\sid}|=0\Rightarrow\text{\code{tcp} stops reading its socket.}
\end{gather*}
Each reply removes one $\upsilon$ from $Q_{h,\sid}$
(Algorithm~\ref{alg:reply}), produced as segment $n$ of D7 with
$p_n=h$; an expired $\upsilon$ is discarded unused; new credit resumes
reading; $h$ sends $\mathrm{fin}$ at world EOF.  By the rule for $x$, a SURB lives at most $X_0+Q=V$,
and a session idle for longer than $V$ holds no credit.
\end{invariant}

\section{Security Laws}\label{sec:laws}

\begin{assumption}[Primitives]\label{as:prim}
AEZ is an ideal enciphering scheme~\cite{Hoang2015}: under a fresh key
a hop does not hold, $\Enc{\tau}{k}(m)=\Pi_k(m\,\|\,0^{\tau})$ for a
uniformly random permutation $\Pi_k$ of $\{0,1\}^{|m|+\tau}$, for
$\tau=0$ and $\tau=16$ alike; $\PRG$, $\MAC$ and HKDF (as a PRF) are
secure, and DDH holds in the group of $\alpha$, so $K_j$ is known to hop
$j$ only.  Network delays $\delta$ are fixed per edge.
$\cl$ departs at $t_{\mathrm{build}}$, whose phase
$t_{\mathrm{build}}\bmod Q$ is uniform and independent of the loop; no hop
other than $g$ observes $t_{\mathrm{build}}$ beyond what $x$ reveals.
\end{assumption}

\begin{defD}{D9}{view}
Over client coins $\rho$ (keys, nonces, header randomness) and delays
$\delta$,
\begin{multline*}
\view_i=(f_i,\bar a_i,\vh i,\frm_i,\nxt_i,e_i,x,b,\\
\arr_i,\dep_i,\chi_i,y_{i-1},\chi_{i+1},y_i),
\end{multline*}
where $\vh i$ is the value position $i$ consumes: $\vh i=v_{k-1}$ (D7's
segment value, $v_0$ the client's input) when $i$ is the symbol hop $h_k$,
and $\vh i=\bot$ when $f_i=\relay$.
\end{defD}

\begin{lawL}{L5}{noninterference}
For loops $P,P'$ let
\begin{gather*}
\pi_i(P)=(f_i,\bar a_i,\vh i,\frm_i,\nxt_i,e_i,x,b),\\
\sigma(P)=f_1\cdots f_H,\\
\pi_i(P)=\pi_i(P')\ \wedge\ \sigma(P)=\sigma(P')\\
\Rightarrow\ \view_i(P)\eqc\view_i(P') .
\end{gather*}
Symbols (shapes) may leak; $\bar a_j$ for positions $j\ne i$, including
an $\mathsf{invoke}$ hop's backend name $\omega_j$, and every segment
value $v_k$ other than $\vh i$ may not~\cite{Goguen1982}, up to registry
inference (Table~\ref{tab:leak}).  On the reply path of a session
symbol, arrival times follow the world (L4's exception) and are excluded
from $\view_i$ there; that residual is Table~\ref{tab:leak}'s session
reply row.
\end{lawL}

\begin{proposition}[L5 from D6, D7, L3, L4]\label{prop:ni}
Under Assumption~\ref{as:prim}, every loop built by
D4c--D7 satisfies L5.  Equality in distribution holds for the carry
alone; the header makes L5 computational (Lemma~\ref{lem:header}).
\end{proposition}
\begin{proof}
Lengths: $|\chi_i|$ and $|y_i|=C$ are constant (D6, L3).  Times:
$\arr_i=\sum_{j<i}(L(f_j)+\delta_j)$ by L4, a function of $\sigma,\delta$,
except on a session reply path, where L5 excludes them.
Headers: $\chi_i,\chi_{i+1}$ reveal only $\lambda_i$, fixed by $\pi_i$ up
to fresh coins (Lemma~\ref{lem:header}).  Carry: uniform at a relay
position (Lemma~\ref{lem:carry}).  If $i=c_k$, it learns $\vh i=v_k$,
which $\pi_i$ fixes.  If $i=p_k$, its output is computed from $\vh i$
and $\bar a_i$.  No component depends on $\bar a_j$ or $v_k$ otherwise.
\end{proof}

L5's premise fixes $\sigma$, hence $H$ and every index, so it says nothing
about length or position; L5$'$ does.

\begin{lawL}{L5$'$}{position hiding}
For loops $P,P'$ with $H(P),H(P')\le\Hm$ and positions $i$ of $P$, $i'$
of $P'$,
\begin{gather*}
\pi^{\circ}_i(P)=(f_i,\bar a_i,\vh i,\frm_i,\nxt_i,x,b),\\
\pi^{\circ}_i(P)=\pi^{\circ}_{i'}(P')\ \Rightarrow\
\mathrm{Adv}_i\le\epsilon_{\mathrm{hdr}}+\frac{|D_i-D'_{i'}|}{Q},
\end{gather*}
where $\mathrm{Adv}_i$ is the advantage in telling $\view_i(P)$ from
$\view_{i'}(P')$, $\epsilon_{\mathrm{hdr}}=\Hm\,\epsilon_{\PRG}
+\epsilon_{\MAC}+\epsilon_{\alpha}$, and
$D_i=\sum_{j<i}(L(f_j)+\delta_j)$ is the delay from the client to
position $i$.  No hop learns its position, $H$, or the symbols elsewhere
in the loop beyond that bound, except the guard: $\frm=\cl$ or $\nxt=\cl$
names position $1$ or $H$, and $\pi^{\circ}$ records it.
\end{lawL}

\begin{proposition}[L5$'$ from Def.~\ref{def:header}]\label{prop:pos}
Under Assumption~\ref{as:prim}, every loop built by D4c--D7 satisfies
L5$'$, and the timing term is tight.
\end{proposition}
\begin{proof}
$|\chi|$ and $C$ do not depend on $H$ or $i$; $e_i$ is the hop's own, and
$x\in\pi^{\circ}_i$.  The carry is uniform at a relay position
(Lemma~\ref{lem:carry}) and fixed by $\vh i\in\pi^{\circ}_i$ at a
consumer.  The header view depends on $\lambda_i$, fixed by
$\pi^{\circ}_i$ up to fresh coins, and on nothing else
(Lemma~\ref{lem:header}); this costs $\epsilon_{\mathrm{hdr}}$.  Time:
$x$ fixes $t_{\mathrm{build}}\in(x-X_0-Q,\,x-X_0]$ (D6), so
$\arr_i-(x-X_0-Q)=u+D_i$ with $u$ uniform on $[0,Q)$
(Assumption~\ref{as:prim}), and the statistical distance between
$u+D_i$ and $u+D'_{i'}$ is $\min(1,|D_i-D'_{i'}|/Q)$, attained by a
threshold test.
\end{proof}

A uniform departure delay does not remove the term: any bounded uniform
offset leaves a shift of $D_i-D'_{i'}$ visible to within its width.  At
$Q=30$\,s a hop one second further from $\cl$ is told apart with
advantage about $3\%$; this is a Table~\ref{tab:leak} row.

\begin{lawL}{L6}{path authority}
$\nxt_i$ is a field of $\lambda_i$, fixed by $\cl$ at construction:
$\nxt_i$ is independent of every $v_k$.  No symbol chooses a hop.
\end{lawL}

\begin{proposition}[Admissible combinators]\label{prop:arrow}
L6 admits the composition fragment ($\then$, without $\mathit{arr}$ or
$\mathit{first}$) of Arrows~\cite{Hughes2000} and excludes monadic bind.
Selective branching~\cite{Mokhov2019} over client-sealed branches needs
L6 weakened to $\nxt_i\in N_i$, a finite set sealed by $\cl$.
\end{proposition}
\begin{proof}
$\then$ fixes every hop before any value exists.
$\mathit{select}:F(A+B)\to F(A\to B)\to F\,B$ fixes the possible effects,
so $\cl$ can seal both branches, but the selecting hop picks $\nxt_i$ by
$v_i$ and learns the branch taken; its law is deferred with Selective
itself.  Bind $m\gg\!\!=k$, $k:A\to M\,B$, chooses the
continuation, and so its hops, from a run-time value: either a hop
constructs $\nxt$ (violating L6) or $\cl$ seals $|A|$ continuations.  This
is the arrows-meticulous, monads-promiscuous separation of
\cite{Lindley2011}.
\end{proof}

Hence the name: a circuit is an onion Kleisli pipeline, a static
composite in $\Kl(M)$.  $M$ is the effect inside one hop; across hops
no bind is exposed, so the structure is not a monad.

\begin{lawL}{L8}{unlinkability}
On consecutive edges $\chi_i\ne\chi_{i+1}$ and $y_{i-1}\ne y_i$ (one layer
peeled, one AEZ layer removed per hop).  If any $y_{k,j}$ is modified to
$\tilde y\ne y_{k,j}$,
\[
\Pr\bigl[\Dec{\tau}{k_{c_k}}(\tilde y_{k,s})\ne\bot\bigr]\le2^{-8\tau}
+\epsilon_{\mathrm{AEZ}},
\]
and a rejected value yields nothing; no bit of a tag survives.  The class
is bound: $\gamma_i=\MAC_{K_i}(b\|\beta_i)$.  Under $F=0$, $b$ is only the
cell length, which $\tau=0$ relays preserve, so a hop re-padding a cell to
$b'\ne b$ would plant a length tag; the next honest hop computes
$\MAC_{K}(b'\|\beta)\ne\gamma$ and drops it
(Algorithm~\ref{alg:hop}, line~\ref{alg:hop:gamma}).  L8 is a
byte-level law; colluders still link by timing (Table~\ref{tab:leak}).
\end{lawL}

Under Assumption~\ref{as:prim} consecutive $y$ are independent uniform
strings to any hop lacking both keys.  A modification propagates through
every later wide-block decipherment, so, unlike counter-mode relay
cryptography~\cite{Degabriele2018}, a flipped bit is never observed in
place; this is Sphinx's wide-block payload~\cite{Danezis2009,Anderson1996}
with AEZ in place of LIONESS.

\begin{lawL}{L9}{replay}
$R_i$ is a family of Bloom filters~\cite{Bloom1970} $R_i[x]$ keyed by the
quantised expiry; $R_i[x]$ grows by blocks of $B$ tags and is dropped when
$x$ passes.  $x$ lies on the $Q$ grid, so at most $V/Q=5$ are live.  A
block is sliced~\cite{Almeida2007}: $K=26$ slices of $M$ bits, one
independent keyed address per slice, and exactly
\begin{gather*}
p_{\mathrm{blk}}=\bigl(1-(1-1/M)^{B}\bigr)^{K}\le2^{-26}\\
\iff M\ge\bigl(1-2^{-1/B}\bigr)^{-1}\approx23638,
\end{gather*}
met by $M=370\cdot64=23680$.  (The estimate $e^{-B/M}$ undercounts:
$(1-1/M)^B<e^{-B/M}$.)
Budgets count units of 16\,KiB: a class-$b$ cell costs $u(b)=b/16\,\mathrm{KiB}$
units, as today's cell buckets charge the full visible size.  A load is
the charge over the $V/Q=5$ aligned quanta
$\lfloor\arr/Q\rfloor-4..\lfloor\arr/Q\rfloor$, with
\begin{gather*}
V=150\,\mathrm{s},\qquad B=16384,\qquad G=64B\ \text{units},
\end{gather*}
$V$ being \code{ONION\_FORWARD\_MAX\_VALIDITY\_MS}, $B$ the per-sender
budget, and $G$ the global budget, a constant of its own that bounds
$R_i$ (Prop.~\ref{prop:replay}), not a sender count.
\emph{Ledgers} are keyed by the sender DID of a live authenticated direct
link.  With $\mathcal R=2(\text{finger slots}+\text{successors}+1)$ the
transport connection-registry capacity (\#723), hop $i$ keeps a partial
map $\Lambda_i:\mathrm{DID}\rightharpoonup\mathbb N$ of loads, and
$\Lambda_i^{\Sigma}$ the global load:
\begin{gather*}
|\mathrm{dom}\,\Lambda_i|\le2\mathcal R,\\
d\in\mathrm{dom}\,\Lambda_i\ \text{released}\iff
\mathrm{closed}(d)\wedge\Lambda_i(d)=0,
\end{gather*}
$\mathcal R$ ledgers for live links and $\mathcal R$ for links closed with
load in the window.  \code{link\_opened}$(d)$ opens $\Lambda_i(d)$, or
finds it if $d$ reconnects; no ledger is recycled or evicted (no LRU).  If
the table is full, \code{link\_opened} refuses the \emph{link}, fail
closed: the shell closes it and the peer redials.  A redial obtains a slot
once a closed ledger drains; that is a liveness assumption, not a
fairness guarantee.  Every cell therefore arrives on a link with a
ledger.

\emph{Charge on receipt.}  Every received cell is charged $u(b)$ to
$\Lambda_i(\frm)$ exactly once, whatever its outcome (invalid $\alpha$,
$\gamma$ failure, replay, expiry, admission), before $\alpha$ decoding and
the ECDH:
\begin{gather*}
\mathrm{charge}_i(\frm,u,\arr)=\mathsf{tk}=(\frm,u,\arr)\\
\iff\Lambda_i(\frm)+u\le B\ \wedge\ \Lambda_i^{\Sigma}+u\le G,
\end{gather*}
adding $u$ to both loads at quantum $\lfloor\arr/Q\rfloor$; otherwise
$\bot$, and the cell is dropped unprocessed.  $\mathsf{tk}$ is affine: it
is consumed at most once, by $\mathrm{admit}_i$, or settled by being
dropped (invalid $\alpha$ or $\gamma$); the charge stands either way, so
no cell is peeled for free.  Admission judges the window at the token's
$\arr$, not at the clock, and requires the filter to be live:
\begin{multline*}
\mathrm{admit}_i((\frm,u,\arr),x,e,\nu)\iff
\arr<x\le\arr+V\\
\wedge\ x>\mathit{clock}\ \wedge\ e=\mathrm{epoch}_i\ \wedge\
\nu\notin R_i[x],
\end{multline*}
then inserts $\nu$ into $R_i[x]$.  The ECDH latency between charge and
admission thus neither widens the window nor puts more than $G$ tags into
one $R_i[x]$ (Prop.~\ref{prop:replay}).  This admission replaces the per-peer
crypto limiter (\code{MAX\_ONION\_CRYPTO\_*}).  A SURB is a layer, hence
single use; L9 also bounds each AEZ key to one carry value
(Prop.~\ref{prop:onekey}).
\end{lawL}

\begin{proposition}[Ledger table]\label{prop:ledger}
Let $c(t)$ be the number of links closed in $(t-V,t]$.
(i) $\mathrm{dom}\,\Lambda_i\subseteq\{\text{live links}\}\cup
\{\text{links closed in }(t-V,t]\}$, so
$|\mathrm{dom}\,\Lambda_i|\le\mathcal R+c(t)$.
(ii) If $c(t)\le\mathcal R$, every live link has a ledger: no honest
neighbour is locked out, and a full table requires churn beyond
$\mathcal R$ within $V$.
(iii) No sender holds a ledger without a live link or one closed within
$V$, so no slot exists beyond them.
(iv) Per DID, $\le B$ units per window under reconnection and identity
rotation.
(v) A link refused at \code{link\_opened} is closed, never served without
a ledger; its redial succeeds once a closed ledger drains (liveness
assumption, not fairness).
\end{proposition}
\begin{proof}
(i) Live links are at most $\mathcal R$ (registry).  A closed link's load
is charged before its close and so vanishes within the $5$ aligned
quanta, at most $V$, after it; the ledger is then released.  (ii) follows
from (i) and $2\mathcal R$ slots; (iii) is the release rule.  (iv) A
ledger is never reset while loaded, and a reconnecting DID finds it; a new
DID needs a real authenticated connection, which the registry bounds, and
obtains its own $B$ only.  (v) is the refusal rule with (i): a closed
ledger drains within $V$.
\end{proof}

\begin{proposition}[Replay bounds]\label{prop:replay}
(i) No admitted layer outlives its filter: $x\le\arr+V$, and
$x>\mathit{clock}$ at admission, so $\nu$ enters a live $R_i[x]$, which
lives until $x$.  (ii) $R_i[x]$ receives only tags whose token has
$\arr\in[x-V,x)$, whatever the delay from charge to admission, hence at
most $G$ tags.  A Bloom filter has no false negatives, so admission
is at most once exactly; a false positive drops a valid cell, the safe
direction, at rate $\le2^{-20}$; memory grows with admitted tags and is at
most $69\cdot76.96\,\mathrm{KB}\approx5.3$\,MB.
(iii) Per neighbour (sender DID $\frm$), even under identity rotation,
hop $i$ charges, hence peels and admits, over any interval of length $T$
at most
\[
B\,\bigl\lceil(\lceil T/Q\rceil+1)/5\bigr\rceil\ \text{units}:
\]
$B$ within $4Q$, a burst of $2B$ within $4Q+\epsilon$ ($B$ at the end of
quantum $q$, $B$ at the start of $q+5$), and $B/V\approx109$
units\,s$^{-1}$ ($\approx1.79$\,MB/s of cells) in the long run, shared by
every loop on that link; $d$ DIDs need $d$ links and obtain at most
$\min(d,2\mathcal R)\,B$ (Prop.~\ref{prop:ledger}).
(iv) The same holds for $G$, $G/V\approx6990$ units\,s$^{-1}$
($\approx115$\,MB/s), in total; a 16\,KiB cell is one unit.  (v) A SURB is usable
only within $[x_\upsilon-V,x_\upsilon)$, so SURB lifetime is at most $V$.
\end{proposition}
\begin{proof}
(i) is the admission window with filters keyed by $x$ and the liveness
conjunct $x>\mathit{clock}$.  (ii) $\mathrm{admit}_i$ tests the window at
the token's $\arr$, not at the admission instant, so $R_i[x]$
receives tags only from charges at $\arr\in[x-V,x)$, which are $5$ aligned
quanta, at most $G=64B$ by the global budget; a late admission after $x$
is refused by $x>\mathit{clock}$ rather than inserted into a dropped
filter.  So $R_i[x]$ has at most $64$ blocks
and a false-positive rate at most $64\cdot2^{-26}=2^{-20}$ (union bound);
every live tag was admitted within the last $5$ quanta, so the $\le5$
live filters hold at most $G$ tags in $64$ full blocks plus one partial
block per filter: $69$ blocks of $KM/8=76960$\,B ($37.6$ bits per tag).
(iii) An interval of length $T$ meets at most $\lceil T/Q\rceil+1$
quanta, covered by $\lceil(\lceil T/Q\rceil+1)/5\rceil$ runs of $5$
consecutive quanta, each charged at most $B$; the ledger is never reset
while loaded (Prop.~\ref{prop:ledger}).  (iv) is the global
ledger, argued alike.  (v) every relay of the reply path applies (i) at the reply's
arrival.
\end{proof}

\begin{proposition}[Throughput]\label{prop:rate}
A single client alone on its links downloads on a class-$b$ loop at most
\[
\min\Bigl(\frac{B}{V},\ (k+1)\,\rho_{\mathrm{f}}\Bigr)\,(C_0-2)
\]
bytes\,s$^{-1}$, $\rho_{\mathrm{f}}$ its forward-cell rate.  At
$b=16$\,KiB,
\[
\tfrac{B}{V}(C_0-2)=\tfrac{16384\cdot13447}{150}\approx1.47\,\mathrm{MB/s},
\]
$\ge1$\,MB/s with $\approx47\%$ headroom, reached with $\rho_{\mathrm{f}}\ge109/(k+1)$; a
larger class $b$ admits $16\,\mathrm{KiB}/b$ as many cells, and the bound
rises towards $B\cdot16\,\mathrm{KiB}/V\approx1.79$\,MB/s as the header's
share falls.
\end{proposition}
\begin{proof}
Every reply cell passes $s$ relays of segment $n$, each admitting at most
$B/V$ cells from its predecessor (iii), and consumes one SURB, of which
each forward cell supplies $k+1$ (Prop.~\ref{prop:batch}); a reply frame
carries at most $C_0-2$ data bytes (D2$'$).  The forward credit cells pass
$g$, segment~$0$ and $h$ under the same per-sender bound, at the required
$109/(k+1)\approx22$ cells\,s$^{-1}$, far below it.  $Q_{\max}$
does not bind while the loop's round trip is below $Q_{\max}V/B\approx2.3$\,s.
\end{proof}

Every loop of one client enters $g$ from $\cl$, so (iii) caps its forward
rate at $B/V$ cells\,s$^{-1}$; with batching that funds $(k+1)B/V$ reply
cells, more than one relay admits, so the reply path, not the client's
credit, binds.

a new pinned golden set in one cutover, without versioning.
\end{lawL}

\section{The Current Design}\label{sec:current}

\begin{proposition}[Backward linkability]\label{prop:current}
Today the exit seals its answer once,
$c=\mathrm{AEAD}_{\mathit{pk}_\cl}(\cdot)$
(\code{encrypt\_client\_payload\_at\_sequence} in
\code{circuit/crypto.rs}), and each relay re-emits it as
$\mathit{payload}=\mathit{frame.payload}$ (\code{advance\_backward} in
\code{circuit/reducer.rs}), rewriting only the edge circuit id and the
outer hop seal.  Every backward relay therefore sees the
same $c$: any two colluding relays, and the exit, link their positions by
equality, independently of route length.
\end{proposition}

\begin{proposition}[Nested layers leak position]\label{prop:nested}
\code{build\_forward\_layers\_with\_ids} nests one envelope per hop, so
hop $i$ decrypts $\mathit{inner}_i$ with
$|\mathit{inner}_i|=\sum_{j>i}\ell_j+|\lambda_H|$, measured at $404$\,B per
downstream hop.  A loop extended after $i$ changes $|\mathit{inner}_i|$,
so $\view_i$ distinguishes it with probability $1$: L5$'$ fails.
\end{proposition}

Cell buckets pad the cell before decryption, not the layer; padding the
innermost layer to a constant total only moves the leak from $H-i$ to $i$.

\section{Related Work}\label{sec:related}

Tor~\cite{Dingledine2004} answers along the circuit it built, as Rings does
today; Degabriele and Stam~\cite{Degabriele2018} formalise the tagging that
its counter-mode relay cryptography admits.  Chaum's untraceable return
addresses~\cite{Chaum1981} and Mixminion's SURBs~\cite{Danezis2003} are the
source of D8; Sphinx~\cite{Danezis2009} gives the fixed-length header and a
LIONESS~\cite{Anderson1996} payload whose zero-block check L8 inherits.
Loopix~\cite{Piotrowska2017} routes traffic as loops for cover; here the
loop is the circuit.  AEZ~\cite{Hoang2015,AEZv5} supplies both the
length-preserving relay layer and robust AE in one primitive.  On the
semantic side, Moggi's Kleisli semantics~\cite{Moggi1991}, generic effects
and handlers~\cite{Plotkin2003,Plotkin2009}, and the
Arrow/Selective/Monad hierarchy~\cite{Hughes2000,Lindley2011,Mokhov2019}
fix which compositions a client can seal in advance.
