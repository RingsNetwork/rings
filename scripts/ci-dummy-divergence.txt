# test functions (scripts/check-transport-independent-modules.py derives them and fails on a point
# without a line here, or a line without a point). Each line is
# `<class> | <file> | <innermost scopes> | <first line of the divergent code>`; a repeated key ends
# in ` #2`, and a reader's code is the values it reads. Classes:
#
# backend         selects the backend, or acts only on values the dummy backend alone produces.
# transport-only  runs only where a transport, processor or swarm exists: its receiver or an
#                 argument holds one, or only such code constructs its receiver.
# inert-hook      the difference is test state that only one build's test code writes, reads or
#                 arms (the simulation runtime, the outbound test trace, held deadlines, witness
#                 accessors); unarmed, both builds act alike.
# failure-bound   the value only bounds how long a failing wait takes.
# unreached       reads a value, takes no transport, and only transport-only code and tests outside
#                 the listed modules reach it. A listed module must not name it (its impl's self
#                 type, else the function); review holds the indirect paths.
